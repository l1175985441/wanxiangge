# 「点得到」自查脚本（阿砚 68 号：真鼠标点到的是别人）

> 为什么给你脚本而不是我扫：**你那台机器才有真 ST 页面**。我这边只有 Chromium + 静态 CSS，
> 量不到你页面的真实堆叠。脚本照她的判据写（`elementFromPoint` 命中是否为自己或子孙）。

## 用法

1. 打开工作台，**把要查的段切出来**（脚本只查**可见**控件，隐藏段查不到是正常的）。
2. F12 → Console → 粘贴下面整段 → 回车。
3. 会打印一张表，并把 JSON 复制到剪贴板（`Ctrl+V` 发我就行）。

```js
(() => {
    const root = document.getElementById('wanxiangge-workspace')
        || document.querySelector('.wanxiangge');
    if (!root) { console.warn('没找到工作台'); return []; }

    const secOf = (el) => {
        const s = el.closest('.wxg-sec');
        if (!s) { return '(无段)'; }
        const t = s.querySelector('.wxg-sec-title');
        return t ? String(t.textContent).trim().slice(0, 12) : '(无名段)';
    };
    const visible = (el) => {
        const r = el.getBoundingClientRect();
        if (r.width < 2 || r.height < 2) { return false; }
        const cs = getComputedStyle(el);
        if (cs.visibility === 'hidden' || cs.display === 'none' || Number(cs.opacity) === 0) { return false; }
        return true;
    };
    const label = (el) => (el.getAttribute('aria-label') || el.getAttribute('title')
        || String(el.textContent || '').trim() || el.id || el.tagName).slice(0, 18);

    const nodes = Array.from(root.querySelectorAll(
        'button, select, input, textarea, a[href], [data-action]'
    ));
    const bad = [];
    for (const el of nodes) {
        if (!visible(el)) { continue; }
        if (el.disabled || el.getAttribute('aria-disabled') === 'true') { continue; }
        const r = el.getBoundingClientRect();
        const x = Math.round(r.left + r.width / 2);
        const y = Math.round(r.top + r.height / 2);
        if (x < 0 || y < 0 || x > innerWidth || y > innerHeight) { continue; }   // 视口外不算
        const top = document.elementFromPoint(x, y);
        if (!top) { continue; }
        if (top === el || el.contains(top)) { continue; }
        const tr = top.getBoundingClientRect();
        bad.push({
            段: secOf(el),
            控件: label(el),
            控件盒: [Math.round(r.left), Math.round(r.top), Math.round(r.width), Math.round(r.height)],
            命中: top.tagName + '.' + String(top.className || '').replace(/\s+/g, '.'),
            命中盒: [Math.round(tr.left), Math.round(tr.top), Math.round(tr.width), Math.round(tr.height)],
        });
    }
    console.log('点根被抢：' + bad.length + ' 处 / 检查 ' + nodes.length + ' 个');
    console.table(bad);
    try {
        copy(JSON.stringify(bad, null, 1));
        console.log('（已复制 JSON 到剪贴板）');
    } catch (e) { console.log('复制失败，手动复制上面那张表即可'); }
    return bad;
})();
```

## 我这边已确认的一处（68 号）

- 状态页三个分段按钮（全部／已做／还没做）被 `.wxg-store` 那条纯文字压住；
- 修法：`.wxg-store/.wxg-ledger { pointer-events: none }` ＋ 可点行/工具条 `position:relative; z-index:2`；
- Chromium 复现：修前命中 `DIV.wxg-store`，修后三个都命中 `BUTTON.wxg-filter`。

## 静态候选（我这边扫 CSS，只有 6 处绝对定位且没设 pointer-events）

`.wxg-panel-grip`、两处 `::before`（状态点、侧栏选中条）、`label.checkbox_label > input::after`、
功能菜单那一块、`.wxg-ws-side-item.is-on::before` —— **都不是会盖住整排按钮的东西**，
所以「点根被抢」多半不是绝对定位引起，而是**正常流里后画的块跟前面的行挤在同一位置**（`.wxg-store` 就是这种）。
这类只能靠你在页面上跑上面那段脚本扫出来。

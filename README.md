# 万象阁 · 安装与使用说明（v0.3.246）

> **万象阁**是一个跑在 SillyTavern（酒馆）里的「世界后台引擎」：
> 世界在后台自己活着——不在场的角色有自己的生活，世界局势与暗线按**世界钟**往前走；
> 你发消息时，引擎当场把"这轮该带什么"送进请求（正文模型看得见）；
> 你每条发言下面挂一张折叠小卡片（你看得见本轮召回了谁、什么事）；
> 数据落在**世界书**里，你能看、能搜、能备份；**正文一个字都不多**。

---

## 一、装它

### 办法 A：扩展管理页安装（推荐）

1. 打开酒馆 → 顶部菜单**「扩展」（Extensions）**。
2. 点**「安装扩展」（Install extension）**，填本仓库地址：
   `https://github.com/l1175985441/wanxiangge`
3. 装好后**刷新页面**（F5），在扩展列表里找到**万象阁**并启用。

### 办法 B：让技术协助者放文件夹

把整个 `万象阁` 文件夹放进：

```
SillyTavern/data/<你的用户名>/extensions/万象阁/
```

放好后刷新页面 → 菜单「扩展」→ 找到**万象阁** → 打开开关。

> ⚠️ 一定要**整个文件夹**一起放（`manifest.json`、`index.js`、`wanxiangge.css`、`core/`、`ui/` 一个都不能少）。

## 二、两个入口

| 入口 | 在哪 | 打开什么 |
| --- | --- | --- |
| 🪄 **魔法棒菜单** | 输入框旁边的魔法棒 → 菜单里有一项「**万象阁**」（带小图标） | ⭐ **独立面板**：自己的标题栏、能关、**能拖**、右下角**能缩放**；位置和大小会记住 |
- **扩展设置区**：只放一颗「打开工作台」按钮（不再在设置区渲染面板）；内容全在**魔法棒面板（工作台）**里。

工作台左栏从上到下是：状态 → 世界状态 → 编年 → 人物名册 → 总控 → 外观 → 召回 → 读取控制 → 自定义 API → 提示词。

## 三、第一次用，按这个顺序

1. **打开面板**（点魔法棒 🪄 →「万象阁」）。
2. **录人物**：到「人物名册」→ 点「**一键盘入预设名册**」立起十几个占位角色，把名字改成你世界里的人；或者点「**从世界书读人**」（留空＝读角色卡绑定那本，只读，不动你的书）。
3. **填别名**：正文里常叫简称（"小西"）就填进那人的**别名**格——别名直接影响能不能召回上。
4. **配自定义 API**：「自定义 API」里填地址／密钥／模型名；云酒馆建议选「**经酒馆服务器转发**」。填完点「**测一下连接**」。
5. **接"手机"好感**（可选）：「读取控制」里「好感数据源」填你那本世界书的名字（例：`手机`）——引擎只**读**，不自己加减、不自己另存。
6. 正常聊天。想在面板里看结果、想手动更新，就用「**立刻更新**」。

## 四、它会做什么

**每回合（你发消息时）**
- 说到谁就带谁的**状态**（好感等）——这一档是"必带"的；
- **世界状态／平行事件**按你这条发言的相关度筛：相关的进、其余排后台（⛔ 不全量灌）；
- 这份内容作为一条**系统注记**跟着你这条消息进请求——**不写进你的聊天记录、不落正文**；
- 你这条发言下面挂一张**折叠卡片**：左栏「人」、右栏「事」，底部一行**回执**（`本轮注入 ✓ 多少字（请求里身份＝系统）`，或 `✕ 0 字 · 原因`）。

**新楼生成后（后台 · 默认留一层缓冲）**
- 自动更新默认**只算到上一层已落定的楼**（刚生成的最新回复你可能还要重 roll 或改字，留到下一轮推进时再进账，防白烧额度；想当场算最新这楼点「**立刻更新**」即可）；
- 更新**世界状态**：局势（势力的碰撞）＋**暗线**（阶段制，挂世界钟，没到点不许提前冒头）；
- 更新**角色七格**：年龄／身份／过去经历／正在经历／所在势力／好感／时间・地点；
- 写**平行事件**与**编年**；
- 更新前**自动留一版快照**，改坏了能「**撤回上一次**」；
- 结果写进世界书《万象阁 · 世界后台》。

**面板里的几页**
- **世界状态**：世界钟、地点、总览、局势清单、暗线清单（每条带阶段／到点条件／现状，可手改）；
- **人物名册**：点一行弹出那个人的**人物卡**（七格＋任务＋他知道什么）；默认**只读**，点右上「⋮」才能改；**改过的格下一轮不许冲掉**（按你的版本保留，并把冲突记一条给你看）；
- **编年**：每回合推演**全部**按时间攒着（⭐ **只给你看**：不注入、不喂模型）；
- **过程报告**：每轮**到底注入了什么**（① 怎么挑的 ② 实际送进请求的内容一字不差，可复制 ③ 回执）；
- **进度**：真实楼层进度（已做多少楼、还剩多少楼，能看出是哪几楼）。

## 五、几个"不是毛病"的事

1. **系统消息会被酒馆归并**：酒馆默认把系统消息合成一大块，所以注入的内容最终出现在**系统区**，而不是紧贴你那一句的上一行。这是酒馆的常规行为，实测模型读得到、用得上。
2. **没接好感数据源时不显示数值**：界面会如实写"未接入数据源"，⛔ 它不会自己编一个数。
3. **世界钟读不出来就写"未知"**：⛔ 不拿占位值凑数；暗线这时**不会推进**（宁可不推，也不提前冒头）。
4. **一轮更新最多两小步请求**：世界状态算一次、十几个角色合并成一次算（拆成两小步防单次输出过长撞 2 分钟超时线，也省你的额度）；不在场的角色按"轮转＋封顶"分到后面几轮。

## 六、常问

**想让它别自动更新？** 面板「总控」里关掉「新楼生成后自动更新」，之后用「立刻更新」手动跑。
**更新失败了怎么办？** 「状态」页的**每轮记录**会写清哪一步失败、原因、试了几次（**重试有上限，不会无限重试**）；点「立刻更新」可以再来一次，点「撤回上一次」能退回改之前。**失败不会把账改乱**（这一轮算作废、账保持原样）。
**怕它碰我的世界书？** 它**只读**你的世界书；它自己的记录写在另一本《万象阁 · 世界后台》里。
**卸载会不会毁数据？** 不会。账本在聊天档案里、记录在世界书里，插件删了也还在。
**手机上能用吗？** 面板在窄屏会自动铺满；拖动／缩放以触摸为准。

## 七、两个"点一下就能自查"的地方（v0.3.58 新增）

**① 体检（面板里点「体检」）—— 一眼看五条**

| 那一行 | 它在替你回答 |
| --- | --- |
| **好感** | 名册里几个人**真读到了数值**（例：`月野育子 81`）。若一个数字都没有，它会提示你去看「手机」那条／「好感数据源」那格填没填；**格子里是文字不是数字**的（如"未接入"）会**单独点名**（⛔ 引擎不擅自改你的数据） |
| **名册** | 带别名几个、身份非空几个（例：`露娜=黑猫露娜`）；**疑似"真身／形态"被拆成两个人物**的会点名（例：`水手月亮`） |
| **名册（第二行）** | ⭐ 现在点「**自动找重复**」**能并出几组**（例：`月野兔⇄水手月亮`）——⛔ 它只报数、**不替你并** |
| **正文** | 上一楼**原文多少字／注入多少字**（原文只有几十字 ⇒ 可能被「四格」剥太狠，去「读取控制」看） |
| **在场（上一楼）** | 上一楼**判了谁在场**——「在场的只准总结正文有的；**其余走推演（放行）**」 |
| **暗线** | 共几条、**有几条被判过编造**（被判过的那几条"现状"不进注入，等你处理） |

**② 名册的两步（专治"同一角色被拆成两条"）**
1. 点「**从世界书读人**」重读一遍 ⇒ 引擎会在**读的那一刻**认属主：条目名（如 `水手月亮`）**并进真身**、`变身形态：…` **写进身份格**（⛔ 手改过的不冲）；
2. 再点「**自动找重复**」⇒ 把**已经存在**的重复并掉（⛔ 引擎不会自己删你已有的人）。
   > 判重认两样：名字／别名互相包含；**或某人的「身份」里写着另一个人的名字**（这就是"真身↔形态"能认出来的原因）。
   > **「关系」条目不算人**（书里 `[角色] 关系：天王遥与海王满` 这种，⛔ 不建人——那两位各自的人物条目才算）。

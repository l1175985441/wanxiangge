# 万象阁 · 安装与使用说明（v0.1.4 · 第一步验证版）

> 这一版只做**两件事**，做完就停下来给你验：
> **① 扩展能装上、界面是中文；② 主线闭环跑通**——你发消息 → 引擎当场召回 → 跟着你这条消息进请求（正文模型看得见）→ 你回复楼下面挂一张折叠小卡片（你看得见）→ 卡片带一行回执。
> 世界状态、暗线、编年、平行事件、一键合并、破限词等等，**都还没做**，按计划在后面几步补。

---

## 一、装它（选一条就行）

### 办法 A：扩展管理页安装（推荐）

1. 打开酒馆 → 顶部菜单**「扩展」（Extensions）**。
2. 点**「安装扩展」（Install extension）**。
3. 把**万象阁文件夹**的地址填进去：
   - 如果你已经把 `万象阁` 这个文件夹放到酒馆能找到的地方（或让技术协助者帮你放），就填它的访问地址；
   - 或者直接把 `万象阁` 整个文件夹（连同里面的 `core`、`ui` 两个子文件夹）**放进**酒馆的扩展目录，然后**刷新页面**、在扩展列表里找到「万象阁」并启用。

### 办法 B：让技术协助者帮你放文件夹

把 `万象阁` 整个文件夹放进这个位置（`<你的用户名>` 换成实际名字）：

```
SillyTavern/data/<你的用户名>/extensions/万象阁/
```

放好后：

1. 回到酒馆页面，**按 F5 刷新**（或手机端下拉刷新）。
2. 菜单「扩展」→ 列表里找到 **万象阁**，把开关打开。
3. 如果列表里没有，检查文件夹结构：`万象阁/manifest.json` 必须在这一层，别多套一层文件夹。

> ⚠️ 一定要**整个文件夹**一起放（`manifest.json`、`index.js`、`wanxiangge.css`、`core/`、`ui/` 一个都不能少）。

## 二、装上之后你会看到什么

打开**「扩展」设置区**，最下面会多出一块**「万象阁」**，点开是中文面板：

| 区域 | 里面有什么 |
| --- | --- |
| 上次更新 | 一行字：上次什么时候更新的、更新了什么、成没成 |
| **账本状态** | 一行字如实报：账有没有**真的存进聊天档**（绿色＝已存 ✓；红色＝存盘失败，只在这会话里；灰字＝还没有账）。刷新后如果发现这行是红的，直接截给我 |
| 总控 | 启用开关、卡片开关（要不要在你每条发言后面挂卡片）、空态卡片、现场保护、严格模式、**「重算本楼」**按钮 |
| 人物名册 | 加人、批量导入、**一键盘入预设名册**（先立起 12 个占位角色，名字随时改）、每人可填**别名／昵称**和**好感** |
| 召回 | 线索回溯楼数（默认 3）、人物条数封顶（默认 8）、排序方式 |
| 提示词 | 注入块开头那句话（可看可改） |
| 现在的进度 | 七步清单，打了勾的就是做好的 |

**所有设置改完即时保存，刷新页面、重开酒馆都还在。**

## 三、这一版怎么用、怎么验

**用法（不用按任何按钮）：**

1. 在「人物名册」里录入几个**你世界里真实角色的名字**（如果名字是「塞西莉亚」这种完整的，直接填；如果正文里常叫简称「小西」，就在**别名**那一格里填上「小西」——别名直接影响能不能召回上）。
2. 好感那格可以先填一个数试效果（真正的"手机好感"接入是第 4 步，见下面第五节）。
3. 正常聊天、正常发消息。

**每发一条消息，会发生两件事：**

- **主模型看得见**：如果你这条消息（或最近 3 楼正文）里说到名册上的人，引擎会把这些人当前的状态（好感等）作为一段临时内容，**附在你这条消息的位置**一起送进请求——这是给正文模型看的，**不会写进你的聊天记录、不会落进正文**。
- **你看得见**：你这条发言的**下面**会挂一张**折叠小卡片**，标题一行，点开是两栏：
  - **「人」**：本轮召回了谁、什么理由（本轮点名／最近正文提到）、他的状态；
  - **「事」**：世界局势那一栏（**这版还是空的**，第 3 步接上）；
  - 底部一行**回执**：`本轮注入 ✓ 多少字（时刻）`，或者 `本轮注入 ✕ 0 字 · 没有说到名册里的人`。

**怎么验证"模型真拿到了"：**

- 卡片回执里出现 **✓ 多少字（请求里身份＝系统）** ⇒ 说明这一轮确实送进去了，并把送进去的**同一份内容**显示给你看（注入和卡片是一份数据、两个面）。
- 想看**这一轮到底送进去了什么**（一字不差）：打开面板里那一节 **「过程报告 · 每轮到底注入了什么」**——每轮点开是三段：**① 怎么挑的**（你的发言、召回了谁、什么理由、带了哪些内容）→ **② 实际送进请求的内容**（可以点「复制这段」）→ **③ 回执**（成没成、多少字、什么身份、为什么没注入）。没召回的那一轮也会留档并写明原因。
- 想验证模型真的用了它：给某个角色填一个明显的好感值（比如 `-50`），然后在正文里提到他，看正文模型的反应是否与这个值一致。
- 不满意就点面板里的**「重算本楼」**，会按当前名册重新算一遍这一楼。

**一件要知道的事（不是毛病）**：酒馆默认会把系统消息**归并成一大块**（设置里的「系统消息归并／squash」）。所以注入的内容最终出现在**系统区**里，而不是紧紧贴在你那句话的上一行。这是酒馆自己的常规行为，官方文档明说"这是把消息以系统身份送出的正规做法"；实测模型能正常读到并用上。

**什么情况会是 ✕（都是如实报出来的，不会悄悄吞掉）：**

| 回执写的 | 意思 | 怎么办 |
| --- | --- | --- |
| `没有说到名册里的人` | 你这条发言和最近几楼都没提到名册上的人 | 正常；把常在正文里出现的角色补进名册 |
| `人物名册还是空的` | 名册没录入 | 去面板录人，或点「一键盘入预设名册」 |
| `总开关关着` | 上面那个「启用万象阁」没开 | 打开它 |
| 只写"最近正文提到"却漏了人 | 正文里用的是**简称**，而你没填别名 | 在他的**别名**格里填上简称 |

## 四、我测过什么、没测过什么（如实说）

### ✅ 测过的（电脑上能跑的，都跑了）

用一份"假酒馆"环境把核心逻辑真跑了一遍，**45 项全过**：

- **认人**：`[角色] 塞西莉亚`、`【雷欧·阿斯特拉】`、`（伊莎贝拉）`、`角色：米拉`、`**莉薇娅**` 都能剥壳认出名字；`# 势力设定`、`人物列表` 这类分类标题会跳过（不乱认人）。
- **召回**：本轮点名的人排最前；关掉严格模式能把最近正文提到的人一起带上；**别名填了就能召回简称**；没有别名时**不误召回**；单字名字不参与匹配（防误撞）；条数封顶生效且**会报出取了几人**（不静默）。
- **注入**：临时内容确实插在**你那条消息前面**；**真实聊天记录一个字都没多**（核对过前后完全一致）；连续重抽**不会出现两份**注入块；打杂生成（摘要这类后台任务）**不掺和**；空召回时**不往请求里塞任何东西**。
- **回执**：注入成功写 `✓ 多少字（时刻）`；失败写 `✕ 0 字 · 原因`；正文还没生成时写"待送"——三种情况都测了。
- **账本**：写进聊天元数据（刷新还在）；设置区里留了底稿（万一酒馆不给元数据存自定义键，还能把账捞回来）；**换聊天＝换一份账**，切走再切回原账还在；楼层删掉会对账清理；**拿不到聊天长度时不动手**（防误清空）；存盘再读回（JSON 转一圈）账本完整——**格式自己下一版读得懂**。

### ❌ 没测过的（我没法在电脑上验，要你在真酒馆里看）

1. **没在真酒馆里装过**——我这边没有酒馆环境。面板挂载、卡片样式、抽屉开合，都是按酒馆官方文档写的，**可能出现位置或样式不对**。
2. **没验证过"正文模型真的用了注入内容"**——我只能验证内容确实进了请求，模型用不用得看你那边。
3. **没在手机端试过**，也没在你的主题／其他扩展共存的情况下试过。
4. **云酒馆的文件保存**：账本主要存在聊天元数据里，我在设置区留了底稿兜底；万一你的酒馆版本不给元数据存自定义键，**从下一次更新起账会走底稿恢复**（这条我没法替你真机验证）。

**所以请你按第三节试两三轮，然后告诉我：卡片长什么样（可以截个图）、回执写的什么、面板有没有挂上。**

## 五、这一版没有的东西（别找了，在计划里）

- ❌ 世界状态、势力的碰撞、**暗线**（阶段制、挂世界钟）——第 3 步
- ❌ 年龄／身份／过去经历／正在经历／所在势力／时间地点这些格子的**自动推进**（格子已经建好了，卡片上也能显示，但**还没有东西去写它**）——第 3、4 步
- ❌ **平行事件**（每个角色自己那条线）、**编年**——第 5 步
- ❌ 从世界书**读人物条目建档**（认人的那段代码已经写好并测过，但界面上的入口在第 3 步一起开）
- ❌ "手机好感"真实数据源接入——**第 4 步**（这一版好感是手填的占位）
- ❌ 生成前拦截之外的更新机制：撤回上一版、重试上限、容量归并、补推历史（含隐藏楼层）——第 6 步
- ❌ 提取／排除四格名单、自定义 API、提示词全套与**破限词**、一键合并／手动改字／玩家棋子——第 7 步

> ⛔ 卸载插件**不会毁数据**（这一版数据都在聊天里／设置里，插件删了也还在）。

## 六、我做的三个假设（可以随时推翻）

1. **最低酒馆版本**写的是 `1.12.0`（保守值）。如果你的酒馆更旧、装不上，告诉我版本号，我改掉。
2. **好感先手填**：真正的"手机好感"我还没接（不知道你那边叫什么名字、放在哪）。在你给出名字／字段之前，引擎**不编也不显示数值**，如实写"未接入数据源"。
3. **名册需要你先录一次**：这版还没做"从世界书读人物条目"的界面入口，所以先手填或点「一键盘入预设名册」。等第 3 步接上世界书，你就不用一个个录了。

## 七、出问题怎么告诉我

按这个格式发最有用：

1. 你做了什么（发了什么消息、点了哪个按钮）；
2. 卡片／面板上看到什么（截图最好）；
3. 浏览器按 **F12** → 「控制台（Console）」里有没有以 `[万象阁]` 开头的红字，有就整段复制给我。

那些 `[万象阁]` 开头的提示都是中文的，不会认不出来。
